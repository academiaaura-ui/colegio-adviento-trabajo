AULA CyT - INSTRUCCIONES

1. Abre index.html para ver la plataforma en tu computadora.
2. Para publicarla gratis en GitHub Pages:
   - Crea un repositorio llamado aula-cyt.
   - Sube index.html, styles.css y app.js.
   - Ve a Settings > Pages.
   - Elige Deploy from a branch.
   - Selecciona main y /root.
3. Para materiales:
   - En Google Drive comparte cada archivo/carpeta como "Cualquier persona con el enlace - Lector".
   - Reemplaza los href="#" de los botones "Abrir" por tus enlaces.
4. Para consultas:
   - Crea un Google Form con Nombre, Grado, Curso, Tema y Consulta.
   - Puedes sustituir el formulario de ejemplo por el enlace del Google Form o insertarlo con iframe.
5. Recomendación:
   - No publiques notas, teléfonos, direcciones ni datos personales de estudiantes.
   - Mantén este sitio únicamente para fines académicos.
